abtk-tasks privacy policy

abtk-tasks is a personal script run by its author on the author's own computer. It has no other users.

  • It requests access to Google Tasks only (scope https://www.googleapis.com/auth/tasks), to create and list tasks in the author's own account.
  • The Google sign-in token is stored only on the author's computer.
  • No Google user data is sold, shared with third parties, or used for advertising.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Contact: via the GitHub account that hosts this page.
